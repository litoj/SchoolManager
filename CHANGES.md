# Changes

## Usability test fixes

### Move

- Cut is named Move, so moving a chapter is easy to find.
- Its icon is a folder with an arrow instead of scissors.

### References from several chapters

- After Move or Add reference, the waiting rows stay marked in every chapter.
- A long press, the row icon or a drag adds a row to the waiting batch or takes it out.
- One Paste places the rows of every chapter at once.
- An emptied batch ends the paste like Cancel.
- Select all mutes while a paste waits, search, sort and navigation stay.
- The picker keeps its picks across chapters, and one Select takes them all.
- A picker tap opens a chapter, so the picks can span folders.
- Back in the picker goes up a level and keeps the picks.

### Filter

- A filter icon beside sort shows on every searchable list.
- The header goes search, select all, sort, filter.
- A phone too narrow for all of them shows only search, the rest waits in More.
- Its dropdown offers name, type, success rate and times tested.
- Description stays in the type row of the filter editor.
- A tag pick opens the editor on that tag.
- A filter applied from a plain list shows its results like a search.
- The filter icon left the search field.

### Filter results

- Times tested and success rate read the word, never its translations.
- So times tested equals 0 lists only untested words.
- A typed translation still finds its word under a number filter.
- With untested rows counted as the lowest, they count as 0 %.

### Import

- A word list with loose words lands in a chapter named after the file.
- At the subjects screen that chapter is a subject.
- A chapter or subject of that name takes the content without a duplicate.
- A file wrapped in the name of the open chapter or subject fills it instead of nesting.
- This holds for word lists and HJSON files alike.
- The import help states the rule.
